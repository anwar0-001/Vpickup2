# Pickups — Browser Edition

## العب على الإنترنت

https://anwar0-001.github.io/Vpickup2/

نسخة ويب ثلاثية الأبعاد مصغرة من Pickups، مستقلة عن مشروع Godot الأصلي، باستخدام HTML وCSS وJavaScript وThree.js.

## التشغيل
افتح مجلد `web-pickups` عبر خادم محلي مثل VS Code Live Server، ثم افتح `index.html`. يحتاج تحميل Three.js إلى اتصال بالإنترنت.

## التحكم
- W/A/S/D أو الأسهم: الحركة والقيادة
- Shift: الركض أو التسارع
- Space: القفز أو فرامل السيارة
- F أو E: ركوب أقرب سيارة أو النزول
- اسحب بالفأرة لتدوير الكاميرا
- N: تبديل النهار والليل
- الهاتف: استخدم أزرار اللمس الظاهرة على الشاشة

تتضمن النسخة مدينة مصغرة مولدة برمجياً، مباني ونوافذ وأشجار وشوارع، سيارات قابلة للقيادة، منظوراً ثالثاً، وتحدي نقطة تفتيش بوقت محدد. الفيزياء والتصادمات مبسطة وهي نموذج أولي وليست لعبة AAA.
